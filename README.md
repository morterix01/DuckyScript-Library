# DuckyScript-Library
A collection of DuckyScript payloads designed for penetration testing, automated system administration, and HID security research. This repository explores the capabilities of USB injection attacks for educational purposes and security auditing.
# 🦆 QuackAttack: Rubber Ducky Payload Library

Benvenuti in **QuackAttack**, una raccolta curata di script e payload in **DuckyScript** per test di penetrazione, automazione di sistema e ricerca sulla sicurezza dei dispositivi HID (Human Interface Device).

## 📂 Struttura della Repository

I payload sono organizzati per sistema operativo e tipologia di attacco per una rapida consultazione:

* **/Windows**: Payload per PowerShell, bypass di UAC e ricognizione.
* **/macOS**: Automazioni per Terminale e script di configurazione rapida.
* **/Linux**: Script per l'estrazione di log e test di vulnerabilità.
* **/Multi-Platform**: Script generici e utilità (es. scherzi innocui o tool di sistema).

## 🚀 Come Iniziare

1. **Scegli il Payload:** Naviga nelle cartelle per trovare lo script adatto alle tue esigenze.
2. **Codifica:** Utilizza il [Ducky Encoder](https://ducktoolkit.com/) ufficiale o tool open-source per convertire il file `.txt` in `inject.bin`.
3. **Carica:** Copia il file `inject.bin` sulla MicroSD del tuo Rubber Ducky.
4. **Esegui:** Inserisci il dispositivo nel target e osserva l'esecuzione.

---

## 🛠️ Requisiti

* **Hardware:** USB Rubber Ducky (Hak5), BadUSB (Digispark, Flipper Zero, Raspberry Pi Pico) compatible with Proximity-Shark (https://github.com/morterix01/Proximity-Shark).
* **Linguaggio:** DuckyScript 1.0 / 3.0.
